# 0004 Apache License 2.0

Status: accepted (2026-11-27)

**Decision:** Pinpoint is licensed under Apache 2.0 (`LICENSE`), with `NOTICE` crediting AutomationGod. It replaces MIT.

**Why:** the owner wants credit and outside contributions. Apache 2.0 requires keeping `NOTICE` and marking changed files, accepts contributions under the same licence (section 5) and includes a patent grant.

**Consequences:** contributors' code stays under Apache 2.0, so a later licence change needs their agreement. Redistributors have to keep `NOTICE`.
